# Ассемблер и интерпретатор УВМ, вариант 7

Ассемблер переводит программу из CSV в машинный код.
Интерпретатор исполняет команды и сохраняет дамп памяти данных в CSV.

## Формат программы

Формат строки — `КОМАНДА,операнд`. Заголовка нет.
Операнд — неотрицательное целое в десятичной записи.
Ассемблер пропускает пустые строки и пробелы вокруг полей.

- `LOAD` (`A=14`, `B` — 27 бит) загружает константу в аккумулятор.
- `READ` (`A=22`, `B` — 16 бит) читает в аккумулятор значение
  по адресу `аккумулятор + B`.
- `WRITE` (`A=12`, `B` — 32 бита) сохраняет аккумулятор по адресу `B`.
- `NE` (`A=4`, `B` — 32 бита) сравнивает значение по адресу `B`
  с аккумулятором и записывает туда `0` для равных или `1` для разных.

## Сборка и запуск

Нужен JDK 17 или новее. `run.sh` собирает программу во временной папке.

```sh
./run.sh assemble source.csv program.bin [--test]
./run.sh interpret program.bin dump.csv start end
```

Ассемблер выводит размер двоичного файла. Флаг `--test` также выводит
семь байтов каждой команды в шестнадцатеричном виде.

`start` и `end` задают границы дампа включительно. Дамп содержит
столбцы `address,value`. Адреса и значения записываются десятичными числами.
Память команд отделена от памяти данных. Изначально аккумулятор
и ячейки данных содержат нули. Адреса данных занимают 32 бита.

## Проверочные программы

Вывод байтов четырёх команд из спецификации и проверка копирования массива:

```sh
./run.sh assemble tests/bytes.csv /tmp/bytes.bin --test
./run.sh assemble tests/copy.csv /tmp/copy.bin
./run.sh interpret /tmp/copy.bin /tmp/copy.csv 40 43
```

Размер `bytes.bin` равен 28 байтам. В ячейках 40–43 дампа `copy.csv`
должны быть значения `7, 13, 0, 25`.

```sh
./run.sh assemble tests/not-equal.csv /tmp/not-equal.bin
./run.sh interpret /tmp/not-equal.bin /tmp/not-equal.csv 60 62
```

В ячейках 60–62 должны быть `0, 1, 7`. Последнее число показывает,
что сравнение сохраняет значение аккумулятора.

```sh
for example in equal different mixed; do
    ./run.sh assemble "tests/vectors-$example.csv" "/tmp/vectors-$example.bin"
    ./run.sh interpret "/tmp/vectors-$example.bin" "/tmp/vectors-$example.csv" 100 128
done
```

Результат записывается в первый вектор по адресам 100–108.
Второй вектор расположен по адресам 120–128.

| Программа | Ожидаемый первый вектор |
| --- | --- |
| `vectors-equal.csv` | `0, 0, 0, 0, 0, 0, 0, 0, 0` |
| `vectors-different.csv` | `1, 1, 1, 1, 1, 1, 1, 1, 1` |
| `vectors-mixed.csv` | `0, 1, 0, 1, 1, 0, 0, 1, 0` |
